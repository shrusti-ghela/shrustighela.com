# Shrusti — Console theme with pretty URLs + Home nav

- Console theme (no base overrides)
- Pretty URLs: /writings/ and /photography/
- Home shows About + News & Publications + Latest posts/photos **with nav bar**
- Writings stored in content/posts, Photography in content/photos
- Multi-image gallery shortcode, floating dark/light toggle

## Run
```bash
git init
git submodule add https://github.com/mrmierzejewski/hugo-theme-console.git themes/hugo-theme-console
hugo server -D --disableFastRender
```
Open http://localhost:1313
